為什麼做這個 App

該有的功能，
不該要付費。

三星的 Notification Edge 從 2019 年之後就沒有再更新；LINE 的通知又只留下每個聊天室的最新一則，訊息一多，前面說了什麼就看不到了。

市面上有 App 能補上這些缺口，但不少要付費才能解鎖完整功能。Sidepeek 想做的事很簡單：把這些功能做好，完全免費，讓每個人都能用。

通知整理

每個聊天室一則，
前面的話都還在。

LINE 原本的通知，每來一則就蓋掉上一則。Sidepeek 把同一個聊天室的訊息收成一則對話預覽，收起來先看最新一句，展開就是整段。

  • 群組和一對一各自一則，通知欄不會被洗版。
  • 每則新訊息照樣提醒，來電不會被藏起來。
  • 直接在通知上回覆、按已讀，沿用 LINE 原本的按鈕。
  • 長網址變短，只有一個連結時會多一顆「開啟連結」。

Peek 條＋側邊欄

從邊緣一滑，
最近的訊息都在這。

螢幕右側、拇指剛好按得到的位置有一條半透明的 Peek 條。往內滑就打開側邊欄，輕點不會誤開；長按可以上下拖到順手的地方。

  • 不只 LINE：IG、Threads、Messenger、Teams，或手機上任何你挑的 App。
  • 點訊息直接跳過去：那則貼文、那個聊天室；在 Threads／IG 點頭像開對方的個人頁。
  • 卡片往左滑刪除，按「清除」全部清掉，5 秒內都能復原。
  • 打字時自動淡出，也可以設定只在桌面出現。

小地方也想好了

資料只在手機上

沒有伺服器、沒有帳號、沒有廣告或分析工具。唯一的連網是下載 LINE 的公開貼圖，和每天檢查一次新版本。

鎖定畫面不露內容

可以選擇在鎖定畫面顯示 Peek 條，但往內滑會先要求解鎖；鎖著的時候，訊息內容不會出現。

貼圖照樣看得到

抓得到就顯示貼圖圖片，抓不到就先顯示佔位圖。只會連 LINE 自己的貼圖伺服器。

不會漏掉提醒

Sidepeek 沒辦法發通知的時候（例如通知權限被關掉），會先保留 LINE 原本的通知，並在 App 裡提醒你。

開源，可以檢查

程式碼全部公開在 GitHub，以 GPL-3.0 授權。好奇它做了什麼，都可以直接看。

安裝

三步開始用

下載並安裝

到 GitHub Releases 下載最新的 APK 安裝。第一次可能要先允許「安裝未知應用程式」。之後有新版，App 會提醒你。

照著設定引導

打開 App，每一步都會帶你到系統裡正確的那一頁：通知存取、顯示通知、側邊欄服務、電池設定。

側邊欄可以晚點開

現在不方便的話，按「稍後再設定側邊欄」。通知整理先能用，之後從 App 最上面的「繼續設定側邊欄」接著做。

開側邊欄服務時跳出「受限設定」？ Android 13 以上，從 APK 安裝的 App 預設不能開無障礙服務。先到「設定 → 協助工具」試著打開「Sidepeek 側邊欄」，被擋住後再到「設定 → 應用程式 → Sidepeek」，按右上角 ⋮ →「允許受限設定」，回去重新打開就可以了。

講電話的時候不能開。 這是 Android 的防詐騙保護，通話中一律不准打開無障礙服務或受限設定。掛斷電話再設定就好。

常見問題

你可能想知道

側邊欄服務（無障礙）會讀我的畫面嗎？

不會。它只用來判斷目前在前景的是哪個 App、是不是在桌面、鍵盤有沒有打開，以及側邊欄開著時接收返回鍵。不讀取、不儲存、不傳送畫面上的任何文字，也不會代替你操作。開啟前 App 會先說明並請你同意。

為什麼通知欄的整理只有 LINE？

Messenger、IG、Threads 這些 App 本身已經會依對話分開通知，所以 Sidepeek 只把它們收進側邊欄，不動它們的通知。LINE 的通知會疊在一起、只剩最新一則，才需要整理。

預覽只顯示「您有新訊息」？

到 LINE →「設定」→「通知」，打開「顯示訊息內容」。LINE 關掉這個選項時，通知裡沒有文字，Sidepeek 也拿不到。

同一則 LINE 訊息響兩次？

到系統的 LINE 通知設定頁，把「聲音和震動」關掉，就只剩 Sidepeek 提醒。「允許通知」要保持開啟，不然 Sidepeek 收不到訊息。

背景常常被關掉、漏訊息？

把 Sidepeek 的電池設成「不受限制」。三星可以再到「設定 → 電池 → 背景使用限制」，把 Sidepeek 加進「永不休眠的應用程式」。其他品牌的設定方式，App 裡有對應說明。

這是 LINE 官方的 App 嗎？

不是。Sidepeek 是個人開發的非官方 App，與 LINE、LY Corporation、Samsung 都無關。
